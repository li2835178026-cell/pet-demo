# 宠伴四端 Demo（pet-demo）

宠物服务产品「宠伴」的四端演示站（纯静态）。

- `00_给贾维斯的任务.md`：需求规格（以此为准）
- `01_图片与页面清单.md`：17 张参考图与页面映射
- `ref/`：17 张参考图
- `AGENTS.md`：仓库工作纪律

## 本地启动

```bash
python3 -m http.server 8080
```

然后打开：

- `/` 演示导航
- `/client/` 用户端
- `/merchant/` 商家端
- `/worker/` 人员端
- `/hq/` 总部后台

建议同时打开 `/client/` 与 `/hq/`：在用户端填入样例并提交，总部端会通过 `localStorage` 自动出现相同编号的待确认需求。重复提交保持幂等；任一端重置后数据同步清空。

本站为零依赖静态演示，不包含真实下单、报名、投保或医疗判断能力。所有业务操作按钮均为禁用的“演示预览”。
